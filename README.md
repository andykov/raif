# Raif PWA mock

Статический PWA-макет по предоставленным скриншотам.

## Как открыть на iPhone

1. Запустите локальный сервер из корня проекта:
   ```bash
   npm run build
   python3 -m http.server 4173 -d dist
   ```
2. Откройте на телефоне адрес компьютера в локальной сети, например `http://192.168.1.10:4173`.
3. Для режима приложения в Safari используйте «Поделиться» → «На экран Домой».

## Навигация в макете

- После заставки открывается экран короткого кода; нажмите `0`, чтобы перейти на главный экран.
- На главном экране кнопка профиля слева сверху открывает личный кабинет.
- Кнопка `Внести 20 127,49 ₽` открывает нижнюю плашку пополнения.
- Блок `19 573,54 ₽ до 8 августа` открывает экран кредита.
